# 泵浦 VFD 控制設計

## STOP：先檢查原廠證據與施工風險

- 若任務要求特定品牌／型號的端子編號、參數編號、接線或保護整定，而對話中沒有最新版原廠手冊，就停止輸出具體編號與數值。只可產出功能需求、訊號類型與待查證清單。
- 若缺少馬達銘牌、VFD 完整型號、電源、感測器輸出、控制電源與接地方式，不得產生可直接施工的接線表。
- 不得把其他系列、相似品牌或既有知識中的端子／參數套用至目前設備。
- 對任何高壓配線、保護旁路、聯鎖解除、Megger、LOTO 或通電試車，必須要求合格電氣人員依現場法規與原廠文件核准。

資料不足時明確輸出：

> 目前只能建立控制功能規格；缺少指定型號的最新版原廠手冊與現場電氣資料，不能確認端子、參數、整定值或施工接線。

## 工作流程

1. 確認泵浦數量、馬達銘牌、電源系統、目標壓力、流量變化、控制位置、環境、通訊與備援需求。
2. 建立控制敘述：啟動許可、PID 定壓、加減泵、輪替、休眠、喚醒、停機與復歸。
3. 建立 I/O 表，至少包含壓力訊號、運轉命令、運轉回授、故障、低水位或低吸入壓、超壓及緊急停止。
4. 建立保護矩陣：過流、過載、缺相、過壓、欠壓、過熱、乾轉、感測器斷線、爆管與頻繁啟停。
5. 明確標示 VFD 品牌與型號相依的端子、參數及接線必須以最新版原廠手冊確認。
6. 每個具體端子或參數都附來源文件名稱、版本／日期與頁碼；無法引用時改列為待確認項目。

## 輸出契約

- 控制需求與假設
- Sequence of Operations
- I/O 表與警報矩陣
- 元件需求清單
- 待確認的原廠參數與現場條件

## 安全邊界

- 不產生可直接施工的最終高壓配線指令，除非已有合格電氣人員審核與適用法規依據。
- 不臆測端子編號、保護整定值或安全迴路。
- 任何旁路、聯鎖解除或保護停用都列為禁止的未核准操作。
- 「常見設定」「建議值」與相似機種資料都不得取代指定型號的原廠手冊。
