# Hung Pump · APP Arwana Codex Plugin

Engineering decision-support skills for vertical multistage pump selection, VFD control planning, pump-system assembly, and Taiwan pump-market analysis.

## Install

1. Download `hung-pump.plugin` from the [latest GitHub Release](https://github.com/Eric-Pan5872117/hung-pump-codex-plugin/releases/latest).
2. Open the downloaded file in Codex and approve the installation preview.
3. Start a new Codex task so the installed skills are loaded.

Current release: `v0.1.0`
